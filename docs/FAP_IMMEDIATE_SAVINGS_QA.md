# Immediate guest savings — QA

The guest's first visible nightly price now has a conservative fee-only illustration immediately below it, on the website, homepage hero, and guest PWA. The property booking card's date-specific price comparison has been moved from below the full breakdown to directly below the trip-total heading. Same-price-basis logic and pre-tax disclosure remain unchanged.

Model example for $100 starting nightly lodging rate:
- Conservative Find A Place guest cost: $107 before taxes, cleaning, promos (assumed 7% service fee)
- Illustrative other-platform equivalent: $118.34 before taxes/cleaning (assumed host fee 15.5%, same host proceeds)
- Preview: 'Could save about $11/night*' (rounded down, fee assumptions disclosed)

This is illustrative, **not** a live competitor quote or a guaranteed saving. Partner guest fees may be 5% rather than the conservative 7% modeled here. The actual date-based comparison still uses the existing API quote and can be lower, equal, higher, or unavailable. It must never claim savings if the compared other-platform price is not higher than FAP.

The package does not change payment charging, nightly/cleaning/pet rates, host cancellation policies, calendar synchronization, taxes, or the final checkout quote.
